# DECODE｜Merchant Websites
此資料夾用於管理 DECODE 為商家製作、提案及交付的網站專案。

## 目錄結構
```text
merchant-websites/
├── README.md
└── xianmanlou/
    └── index.html
```

## 專案規則
- 每家商家使用一個小寫英文識別名稱（slug）作為子資料夾，例如 `xianmanlou/`。
- 保留各客戶專屬的 LOGO、圖片及菜單，不得複製到其他客戶網站。
- 正式上線前核對營業時間、菜色、價格與照片授權，並完成手機/桌機測試。
- 商家網站不應自動合併進 DECODE 官方網站的正式部署分支。
- 目前儲存庫 `decodecmwork/decode` 為 **public**，此分支也可被公開存取；正式接案建議另建 **private** 的客戶網站程式庫。
